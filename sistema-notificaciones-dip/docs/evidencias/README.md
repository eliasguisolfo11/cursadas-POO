# Evidencias de ejecución

- `parte-1-inicial.txt` y `canales-dip.txt` contienen la salida estándar capturada al ejecutar las clases `MainParte1` y `Main` después de compilar el proyecto.
- Los PNG muestran esa salida con formato de consola para facilitar su lectura y entrega.
- `parte-1-inicial.png` acredita el canal de correo de la implementación inicial.
- `canales-dip.png` muestra Email, WhatsApp, SMS, Push, el envío múltiple opcional y el historial consultado mediante DAO.
